# homebrew-tap

Personal Homebrew tap.

```sh
brew tap muarifer/tap
```

## Casks

| Cask | Description |
| --- | --- |
| [`kitty-taskbar`](https://github.com/muarifer/kitty-taskbar) | Menu bar taskbar for kitty terminal windows and tabs |

```sh
brew install --cask --no-quarantine kitty-taskbar
```
